# QTAWEBSITE
QTA.org.uk website build in Framer. Start with [BUILD-STATUS.md](BUILD-STATUS.md).

- `source/`: the build brief and the approved HTML prototype
- `framer/code/`: Framer code components (jurisdiction switch and law components)
- `framer/cms/`: Courses and Dates collections
- `framer/custom-code/`: head code (structured data)
- `scripts/`: data extraction, Framer setup, link check

`npm install`, then `npm run check`.
